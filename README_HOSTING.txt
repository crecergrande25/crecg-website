CRECER GRANDE WEBSITE V1.9.1 — HOSTING READY

This is a fresh static production build for GitHub Pages and https://crecergrande.in.

IMPORTANT UPLOAD METHOD
1. Delete old repository website files if you want a clean deployment.
2. Upload the CONTENTS of this folder to the repository root.
3. index.html must be directly in the repository root.
4. Keep CNAME and .nojekyll.
5. GitHub Pages should publish main / (root).
6. Do not change HostingRaja DNS if the domain is already working.

AFTER DEPLOYMENT CHECK
- https://crecergrande.in/
- /products.html
- /divisions.html
- /estimate.html
- /contact.html
- /sitemap.xml
- /robots.txt
- /admin/ (local-only catalog editor; not secure centralized authentication)

V1.9.1 DESIGN/RELIABILITY PRINCIPLES
- Static HTML content remains visible even if JavaScript fails.
- Public product cards are serverless/static HTML, so a JS error cannot blank the catalogue.
- Header/footer are written into every page rather than injected at runtime.
- JavaScript is limited to mobile navigation, filters, enquiry helpers, calculators and local admin.
- Century Gothic is preferred through the CSS font stack; no font files are bundled.
- The final Crecer Grande logo is used in a web-optimized copy.
