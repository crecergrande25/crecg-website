CRECG WEBSITE V6 — START HERE

LOCAL REVIEW
1. Extract the ZIP file.
2. Open Command Prompt / Terminal inside the extracted Crecer_Grande_Website_V6 folder.
3. Run:
   python -m http.server 8000
4. Open in your browser:
   http://localhost:8000
