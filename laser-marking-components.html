Compatibility first

Identify the exact requirement before ordering.

F-theta scan lenses are application-specific optical components used with galvo systems. Matching only physical appearance is not enough; design wavelength, focal length, field size and mounting details matter.

Please share

  • Marking machine make/model
  • Laser type: fiber / CO2 / UV / other
  • Laser wavelength if known
  • Current field-lens marking size / focal length
  • Lens mounting thread
  • Existing part number and photos
  • Required scan/marking field
