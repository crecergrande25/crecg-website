Privacy Notice

How the current Crecer Grande website handles information and external communication links.

Website enquiries

The current static website uses WhatsApp and the visitor's email client as the main submission routes. A browser-local draft may also be retained on the device used to prepare an enquiry. Crecer Grande does not currently operate a central website enquiry database through GitHub Pages.

Admin area

The website admin included with this static release is a local product-management draft tool. Its passphrase and local edits remain in that browser and are not production-grade online authentication. Confidential business or customer information should not be stored in it.

External services

Links may open WhatsApp, email, Instagram or other external services. Their own privacy terms apply when those services are used.

Future backend

If a secure online backend, analytics platform, file-upload service or other data processor is added later, this notice should be updated to identify the relevant processing purpose and provider.
