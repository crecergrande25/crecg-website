## Admin note
/admin/ is included as a browser-local product-draft manager. It is intentionally noindex and is not secure online authentication. On the current static GitHub Pages architecture, publish product changes by exporting catalog.json and replacing assets/data/catalog.json in the repository. A secure backend is required for instant multi-device live publishing.
